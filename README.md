# Les Klosques — site vitrine

Site responsive HTML/CSS/JavaScript pour publication via GitHub et Cloudflare Pages.

## Adresse de contact mise à jour
Les demandes préparées depuis le formulaire et les liens de contact sont adressés à **antoine.darcq@laposte.net**.

## Publication Cloudflare Pages
- Dépôt GitHub : téléverser les fichiers à la racine.
- Framework preset : None
- Build command : `exit 0`
- Build output directory : `.`

## Limites actuelles
Le formulaire ouvre le logiciel de messagerie du visiteur : il ne transmet pas automatiquement le message et ne stocke aucune demande côté serveur. La synchronisation Google Agenda n'est pas encore implémentée. Elle nécessitera une intégration Google OAuth sécurisée et un backend/base de données. Ne jamais publier de secret ou de jeton Google dans ce dépôt public.
